# Парковки Санкт-Петербурга — сгенерированный продукт

Код целиком сгенерирован конвейером RWB AI Hack по требованиям кейса №1 (прогон `cad22849`).
Модель не писала C#-обвязку: каркас, API, EF Core, фронтенды и стенд собраны детерминированно
по спецификации; модель написала только тела хуков бизнес-правил (`backend/src/App.Domain/Hooks`).

## Запуск

Нужен Docker с Compose v2 (Linux, macOS или Windows с Git Bash):

```sh
./run.sh
```

Скрипт собирает образы (зависимости .NET 10 и npm скачиваются внутри сборки) и поднимает стенд:
PostgreSQL, WireMock, API, worker, админка и мобильное приложение водителя. В конце печатает адреса.
На первом экране выберите роль: ROLE-02 — администратор, ROLE-01 — водитель.

## Что внутри

- `backend/` — ASP.NET Core 10, Minimal API с правами по ролям, EF Core, хуки бизнес-правил, тесты xunit.
- `admin-web/`, `mobile-web/` — Angular: админка и PWA водителя, E2E на Playwright.
- `infra/docker-compose.yml` — стенд; `infra/smoke.py` — smoke-проверка под каждой ролью.
- `docs/` — отчёт: статус критериев приёмки, трассировка требований, эксплуатация.
- `reports/` — результаты проверок прогона.
- `.gitlab-ci.yml` — CI продукта с теми же командами, что проверял конвейер.
