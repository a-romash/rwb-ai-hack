
## 13. Направление FRONTEND: веб и мобильное приложение

**Миссия.** Шаблоны интерфейсов, на которых пайплайн собирает удобные, единообразные и проверяемые экраны для любой роли и платформы. Плюс Studio — интерфейс самого пайплайна.

### 13.1 Зона ответственности

- Шаблон админки на Angular, фасад дизайн-системы и рендерер экранов из UI-IR.
- Studio пайплайна (Angular).
- Шаблон Android-приложения на Kotlin и рендерер экранов Compose из UI-IR.
- Инфраструктура UI-тестов: Playwright, Robolectric, Roborazzi, page objects из UI-IR.
- Снимки экранов для документации.

### 13.2 Админка: шаблон на Angular 20.1.6

```text
admin/
  package.json                 # точные версии: @angular/* 20.1.6, @angular/material 20.1.x,
                               # @maplibre/ngx-maplibre-gl 20.x, maplibre-gl 5.x
  src/app/
    core/        auth (функциональный interceptor, guard), api/ (сгенерированный клиент — не править),
                 sse/ (fetch + ReadableStream → signal), config, обработка ошибок ProblemDetails
    ui/          фасад дизайн-системы: app-page, app-data-table, app-filter-bar, app-status-chip,
                 app-map-view, app-timeline, app-kpi-card, app-empty-state, app-confirm-dialog,
                 app-form-field, app-json-viewer
    features/<feature>/   ленивые маршруты; страницы списка, карточки, формы, карты и таймлайна —
                          из UI-IR; нетиповые компоненты — с «дырами»
  e2e/           Playwright: page objects генерируются из testid UI-IR; тесты пишет агент QA
```

| Решение | Почему |
|---|---|
| Standalone-компоненты, signals (`signal`, `computed`, `input()`, `output()`), `OnPush` везде, новый control flow (`@if`, `@for`, `@defer`), типизированные формы, функциональные guards и interceptors | Стабильные API Angular 20; меньше шаблонного кода — меньше места для ошибок малой модели |
| API со статусом experimental или developer preview в 20.1.6 не используем. Zone.js оставляем (zoneless стабилен с 20.2) | §2.4. Список сверяется с документацией версии при сборке шаблона |
| **Фасад дизайн-системы** поверх Angular Material: около 12 компонентов с узким API | LLM и генератор работают с маленьким задокументированным API (шпаргалка ≤ 30 строк), а не со всей библиотекой. Kit можно заменить, не трогая экраны |
| Клиент API генерируется из OpenAPI (openapi-generator, `typescript-angular`) | 0 токенов; контракт не расходится с бэкендом |
| SSE читается через `fetch` + `ReadableStream`, а не через `EventSource` | **[Факт]** `EventSource` в браузере не умеет передавать заголовок `Authorization`. Токен в query string — утечка в логи. Чтение потока через `fetch` — около 40 строк и без новых зависимостей |
| Карты: MapLibre GL JS через `@maplibre/ngx-maplibre-gl` 20 (версия под Angular 20 по [npm](https://www.npmjs.com/package/@maplibre/ngx-maplibre-gl)) | Векторные тайлы зон из PostGIS (`ST_AsMVT`) тянут десятки тысяч сегментов. Подложка — локальный PMTiles-экстракт города, если он подготовлен; иначе карта без подложки, но с зонами и машинами. Атрибуция OSM обязательна |
| Стабильные `data-testid="<screen>.<element>"` на всех интерактивных элементах — из UI-IR | Тесты не ломаются от вёрстки; page objects генерируются |
| Доступность: `@axe-core/playwright` в E2E; гейт — ноль нарушений critical и serious | Качество интерфейса проверяется кодом |
| Unit-тесты на Jest (`jest-preset-angular` в версии с поддержкой Angular 20 фиксируется в шаблоне), E2E на Playwright, линтер — angular-eslint + Prettier | ADR-16 |

**Дизайн-токены.** Цвета, типографика, отступы и радиусы задаются CSS-переменными и темой Material 3. Цвет несёт только смысл и одинаков в вебе и мобильном приложении: зелёный — оплачено или пройдено, жёлтый — скоро истекает или внимание, красный — истекло или ошибка, серый — вне зоны или бесплатно.

**Экраны админки для кейса №1** — выход стадии S3 в UI-IR:

| Экран | Что на нём | Роли |
|---|---|---|
| Вход | Логин, пароль, демо-учётки на стенде | Все |
| Обзор | Карта: машины, зоны, активные сессии. KPI: активные сессии, истекают в ближайшие 10 минут, смены зоны за сегодня, предупреждения. Живая лента событий | Диспетчер, администратор |

| Сессии | Список с фильтрами по статусу, ТС и периоду. Карточка с таймлайном событий сессии | Диспетчер, администратор |

| Симулятор | Выбор маршрута, скорость воспроизведения, старт и стоп, перемотка таймеров сессии (только в профиле `demo`) | Администратор |

### 13.3 Studio — интерфейс пайплайна

| Экран | Главное действие | UX-паттерн ([Smashing](https://www.smashingmagazine.com/2026/02/designing-agentic-ai-practical-ux-patterns/), [Microsoft HAX](https://www.microsoft.com/en-us/research/project/guidelines-for-human-ai-interaction/)) |
|---|---|---|
| Новый прогон | Вставить текст или загрузить файлы (PDF, DOCX, MD, изображения, наборы данных), выбрать автономию и проект GitLab | Autonomy Dial; ожидания при первом контакте |
| Анализ | Исходник с подсветкой фрагментов REQ. Неоднозначности по характеристикам ГОСТ. Карточки вопросов: варианты, ответ по умолчанию, «почему спрашиваем». Кнопка «Принять все по умолчанию» | Explainable Rationale |
| Спецификация | Домен (диаграмма), правила, AC в Gherkin, события, API, экраны, дифф версий. Кнопка «Заморозить v1» | Intent Preview |
| Прогон | Лента стадий и агентов. Доска AC «красные → зелёные». Бюджеты токенов, времени и попыток вживую. Журнал. Кнопки «Стоп» и «Откат к зелёному коммиту» | Action Audit & Undo |
| Паспорт | Вердикты AC, трасса REQ → … → стенд, гейты. Ссылки на MR, CI, стенд, APK и документацию | Confidence Signal |
| Эффективность | Таблицы и графики по стадиям и агентам, сравнение прогонов | Прозрачность стоимости |
| Настройки | Эндпоинт модели, профиль контекста (определяется автоматически), бюджеты, параллельность | — |

**Тон интерфейса** — спокойный и инженерный, без «я подумал». Например: «Найдено 9 неоднозначностей», «AC-07 застрял: нужна граница округления суммы».

**Расширения из списка кейса:**
- голосовой ввод требований через локальный faster-whisper — кнопка «Надиктовать»;
- плагин IDE для запуска стадий из редактора.

### 13.4 Мобильное приложение: шаблон на Kotlin 2.2.21

```text
mobile/
  gradle/libs.versions.toml    # Kotlin 2.2.21, AGP, Compose BOM и др. — закреплены и проверены сборкой шаблона
  app/src/main/java/<pkg>/
    App.kt                     # Application + AppContainer (ручной DI, ADR-17)
    core/network/              # клиент API из OpenAPI (openapi-generator, kotlin + retrofit2 + kotlinx.serialization),
                               # OkHttp, okhttp-sse, interceptor авторизации
    core/location/             # LocationSource: Fused | Platform | DemoRoute; TrackingService (foreground service)
    core/notifications/        # каналы, публикатор уведомлений, локальные таймеры, дедупликация по eventId
    core/storage/              # DataStore: сессия, настройки, офлайн-очередь телеметрии
    core/ui/                   # тема и токены; фасад: ZoneCard, SessionTimer, StatusBanner, PrimaryButton,
                               # EmptyState, MapView (MapLibre Native)
    feature/<feature>/         # Screen + ViewModel + UiState из UI-IR; логика — «дыры»
  app/src/main/assets/demo-routes/*.geojson
  app/src/test/                # ViewModel-тесты (coroutines-test, Turbine), Compose UI-тесты на Robolectric,
                               # снимки экранов Roborazzi для документации
```

| Тема | Решение | Основание |
|---|---|---|
| Геолокация в фоне | Foreground service с `android:foregroundServiceType="location"`, разрешения `ACCESS_FINE_LOCATION`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION`. Сервис запускается кнопкой «Начать смену», пока приложение на экране | **[Факт]** Для приложений с targetSdk 29+ foreground service, использующий геолокацию, обязан объявить тип `location` ([Android Developers](https://developer.android.com/develop/background-work/services/fgs/changes)). **[Вывод]** Если сервис запущен из видимого приложения, фоновое разрешение не требуется. Это проще для пользователя и для проверки |
| Частота точек | 5 с в движении, 15–30 с на стоянке. Отправка пачкой раз в 10 с или по 20 точек. Офлайн-очередь в DataStore, досылка через WorkManager | Баланс точности, батареи и трафика |
| Геофенсинг | Не системный: зона определяется на сервере | **[Факт]** Лимит системного геофенсинга — 100 геозон на приложение ([Android Developers](https://developer.android.com/training/location/geofencing)) |
| Уведомления | `POST_NOTIFICATIONS` (Android 13+). Каналы: «Зоны» и «Сессия» — высокий приоритет, «Служебное» — низкий (уведомление сервиса) | Политика Android 13+ |
| «За 10 минут до конца» | Таймер внутри foreground service (корутина до момента T−10, пересчёт при изменениях) **и** событие сервера по SSE. Дубликаты отсекаются по `eventId`. Точные будильники не используем | **[Факт]** Начиная с Android 14 разрешение `SCHEDULE_EXACT_ALARM` по умолчанию не выдаётся новым установкам приложений, нацеленных на Android 13+ ([ProAndroidDev](https://proandroiddev.com/beyond-doze-building-reliable-background-execution-on-modern-android-including-oem-realities-5fa0a6e05672)) |
| Демо-маршрут | `DemoRouteLocationSource` проигрывает GeoJSON из assets с множителем скорости ×1…×20. Переключатель в настройках | Кейс прямо разрешает «демонстрационный mock-маршрут» |
| Время | Таймеры считаются от серверного «оплачено до» с поправкой на смещение часов устройства, которое вычисляется по ответам сервера | Устройство не источник истины |
| Оплата | Кнопка «Перейти к оплате» открывает официальный сервис: приложение, если оно установлено (пакет в конфигурации города), иначе сайт `parking.spb.ru`. Отметка «Я оплатил до …» | Свой платёжный механизм не нужен (кейс) |
| Карта | MapLibre Native Android: сегменты зон, «коридор» ±10 м вокруг текущей зоны, позиция, трек | Без ключей API; та же подложка, что в вебе |
| Без KSP и kapt | Ручной DI, DataStore | ADR-17 |
| Проверки | `./gradlew assembleDebug testDebugUnitTest lintDebug detekt`; ktlint; APK — артефакт CI | Сборка без эмулятора |

**Экраны мобильного приложения для кейса №1:**

| Экран | Что на нём |
|---|---|
| Онбординг и разрешения | Зачем нужны геолокация и уведомления. Согласие на обработку геоданных во время смены (152-ФЗ). Трекинг только во время смены |
| Вход | Логин или демо-учётка |
| Главная (карта) | Позиция, ближайшая зона (линия и коридор), баннер состояния: «В зоне платной парковки» или «Вне платной зоны». Карточка зоны: номер, адрес, тариф сейчас, «платно сейчас» или «бесплатно до 08:00», минимальное время, шаг |
| Сессия | Старт или подтверждение: длительность от `minTime` с шагом `timeStep`, оценка стоимости, «Перейти к оплате», «Я оплатил до …». Активная сессия: «Оплачено до 15:20», обратный отсчёт, «Продлить», «Завершить» |
| Уведомления | Лента с типами и временем |
| История | Сессии; маршрут дня на карте |
| Настройки | ТС: госномер, категория. Город, демо-маршрут, адрес сервера |

**UX для водителя.**
- Главное считывается одним взглядом: крупный статус, время «до 15:20», один основной CTA.
- Кнопки не меньше 48 dp.
- При скорости больше 10 км/ч действия, требующие ввода, заблокированы с пояснением «Доступно на стоянке».
- Тёмная тема, подписи для TalkBack, корректные русские формы: «осталась 1 минута», «осталось 10 минут».

### 13.5 Definition of Done направления Frontend

- Шаблон админки и шаблон Android-приложения собираются из пустого IR и из IR кейса №1. Экраны проходят axe (веб) и Robolectric-тесты (мобильное).
- Фасадные компоненты задокументированы в шпаргалке для агентов (≤ 30 строк на платформу) и покрыты собственными тестами.
- Генератор page objects и testTags работает для любого UI-IR.
- Снимки экранов из E2E (Playwright) и Roborazzi автоматически попадают в `docs/`.
- Studio показывает прогон вживую, паспорт и отчёт эффективности.
