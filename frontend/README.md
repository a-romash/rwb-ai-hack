# Студия «Поток»

Веб-интерфейс ИИ-пайплайна: требования проекта, линия из 10 этапов, запуск агентов и их результаты.

Angular 20.1.6, Taiga UI 5.30, `@angular/cdk`. Шрифты Inter и JetBrains Mono подключены локально — Студия работает без внешних CDN. Визуальный язык описан в [DESIGN.md](DESIGN.md).

## Запуск

Вместе с бэкендом — из корня репозитория:

```sh
docker compose up --build -d
```

Студия откроется на [http://localhost:8080](http://localhost:8080).

Для разработки интерфейса поднимите Compose, затем:

```sh
cd frontend
npm ci
npm start
```

Dev-сервер на [http://localhost:4200](http://localhost:4200) проксирует `/api` на Compose (`localhost:8080`).

## Проверки

```sh
npm run build          # продакшен-сборка с бюджетами размера
npm run e2e:install    # один раз: Chromium для Playwright
npm run e2e            # сценарии и проверка доступности axe, API подменяется
```

E2E-тесты не требуют бэкенда: ответы API подменяются в `e2e/fixtures.ts`. Сценарии гоняются на десктопе (1440 px) и на телефоне (Pixel 7), axe — в светлой и тёмной теме.

## Что внутри

| Экран | Что делает |
|---|---|
| Проекты | Список со строками-миниатюрами линии потока, поиск, сортировка. Для пустого списка — вступление со схемой этапов |
| Новый проект | Редактор требований как документ: загрузка `.md` и `.txt`, шаблон разделов, пример из кейса, подсказка полноты, `⌘↵` |
| Поток | Граф этапов, как в GitHub Actions: разработка и проверки идут параллельными ветками. Описание этапа: вход, выход, проверка, агент, последний запуск |
| Требования | Правка с явным сохранением (`⌘S`), защита от потери изменений, подсказка полноты |
| Запуски | Живые статусы задач агентов, длительность, результат с подсветкой JSON, допущения |

Командная палитра `⌘K` / `Ctrl+K` открывает проекты, разделы и смену темы.

## Структура

```text
src/app/
  core/api/        HTTP-клиент и типы ответов бэкенда
  core/pipeline/   справочник этапов и агентов, трактовка статусов
  core/state/      состояние на signals: проекты, запуски, здоровье API, тема, уведомления
  core/util/       время, текст, подсказки по требованиям, пример кейса
  shared/ui/       линия потока, редактор требований, статусы, результат, диалоги, уведомления
  features/        экраны: shell, projects, composer, workspace, not-found
src/styles/        токены дизайн-системы, связка с Taiga UI, базовые стили
e2e/               Playwright: сценарии и axe
```

Правила разработки, дизайн-токены и Definition of Done — в [AGENTS.md](AGENTS.md). Что фронтенд ждёт от API — в [CONTRACT.md](CONTRACT.md).
